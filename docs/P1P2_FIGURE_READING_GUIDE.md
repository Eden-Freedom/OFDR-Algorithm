## P1 Figure 1：NUFFT与直接NUDFT复谱差

横轴 Reference / Measurement真实物理信号，纵轴在ROI抽样空间k bins上的 **复数谱相对L2误差**（无量纲）。必须使用相同估计坐标qtrue、窗、Voronoi密度权重和傅里叶指数。该图不显示Oracle Gauge RMSE，不能把小的复谱误差直接认作应变误差也很小。

## P1 Figure 2：耦合随机散射场的密度对Oracle应变误差影响

横轴嵌套散射单元宽度（mm，图中从粗到细），纵轴非零应变5με下Oracle Core RMSE（με）；两条曲线分别为9-bin复相位平均与raw gauge phasor。跨密度使用同一底层Gaussian随机测度，**每个trial使用同一Core有效掩码**。观察是否存在稳定趋势，绝不能只凭4次均值宣称统计收敛。图像没有给出完整PSF/边缘10–90%宽度，空间分辨率尚待独立核查。

## P2 Figure 1：四组解调结果随施加应变变化

横轴应变0、1、5、10με，纵轴各trial在固定Core掩码上的RMSE均值（με）。四曲线依次为00 Oracle、10仅共模、01仅差模、11共模+差模（原独立SSWT）。关键是非零应变时10相对00的分离，而不只是11相对00的差。零应变00/10理论接近0，是当前理想化模型的不变量，不是任何真实OFDR都具有的普遍零误差。

## P2 Figure 2：有符号交互效应

上图横轴施加应变（με），纵轴平方误差对比量（με²）：C=M10-M00、D=M01-M00、I=M11-M10-M01+M00；正负都有解释，不能要求各项为非负或直接按RMSE平方差划分正交噪声功率。下图横轴施加应变，纵轴I与完整trial bootstrap 95%CI；区间跨零不能说明精确可加，也不能说明噪声独立，须结合试次分布及样本量。

## P2 Figure 3：单一实现的空间应变恢复示意

横轴Gauge中点位置（m），纵轴恢复的Gauge平均应变（με）。黑线为仿真真值的Gauge平均；其他四曲线为当前示例trial的4组估计，NaN代表共同位置无效。应关注应变区边缘、位移平台、两侧静止区、衰落位置和尺度，而不将单一散射实现当作总体表现。绘图取最大预设应变10με，但归因统计来自全部trial。

## 数值与解释底线

- 所有方法共享时间采样、光频窗、密度权重、同一物理配对信号与对应trial内固定的Core/Static掩码；不得在每条曲线上换最优位置。
- P1与P2各自独立新种子流程；不同试次、不同散射密度与旧V6d均值不应直接相减当成因果主效应。
- 当前Oracle的非零应变误差不代表不可突破的噪声底限；任何声称真实空间分辨率的结果都需要PSF与边缘响应独立验证。
