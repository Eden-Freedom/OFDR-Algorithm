# P2b：OFDR非零应变下共模光频误差方向灵敏度预测（新开发期预设协议）

> 状态：P2b已提交第一版研究代码，尚未在用户MATLAB实机运行。此次实验从已查看的P2旧试次完全分离，但**首轮仅是新的开发机理数据，不是独立冻结验证**。冻结运行主动锁定。所有源代码均在 `matlab/mechanism_p2b/`，不改V6/V7d/P1/P2原数学核。

## 研究动机

2026-11-14 P1c 用户已知开发种子上，509个固定Core Gauge进行直接NUDFT vs NUFFT比较：Oracle Core RMSE为0.14472769/0.14471644με，逐Gauge数值差RMS为0.0001029903με，反三角约束成立；因此在**该设置**下无法将Oracle残余主要归因于NUFFT近似。P1b耦合散射密度数据n=4仍未证明连续散射模型收敛，真实设备的物理泛化未验证。

旧P2的8个开发试次已查看：共模误差仅注入时，相对Oracle的MSE增量C在1/5/10με分别为+0.0052708/+0.018078/+0.017510με²，各8/8次为正且trial bootstrap CI95高于0。但C不随ε简单单调增加；该现象仍需建立**可预测的模型**，不能把已查看数据反复用于拟合或独立检验。

## 1. 数学定义与可证伪预测

固定同一真实扫频、同一参考Rayleigh信号、同一施加应变ε下的测量物理信号。由两条辅助估计产生 **仅供机理注入** 的共模误差方向：

`e_c(t)=(qhat_ref(t)+qhat_meas(t))/2-qtrue(t)` (Hz)。

四个应变水平固定为 `ε=[0,1,5,10] με`。对于共模尺度 `α`，两次主波形分别以**同一**光频坐标 `qtrue+α e_c` 重构。

`F_epsilon(α,z)=D[R(s_ref,qtrue+αec),R(s_meas(ε),qtrue+αec)]_z`

其中 `R` 复用原V6窗、权重、NUFFT，`D` 复用原V6c 9-bin复Gauge解调，不在任何一组更换时间窗、真值或实际散射系数。

先在 `α=0` 处固定Oracle残差 `r0(z)=F_epsilon(0,z)-ε_true(z)`。用独立于最终测试幅度的中心差分估计：

`g_h(z)=[F_epsilon(+h,z)-F_epsilon(-h,z)]/(2h)`

预先固定 **主差分 h=0.05**；**次差分 h=0.10** 仅用于步长灵敏度检查，禁止根据实际Core评分事后选择h。最终评价的 `α=[0.5,1]` **没有用于局部方向导数计算**。

预测的共模平方误差增量：

`Cpred(α)=2α mean_core(r0*g_h)+α² mean_core(g_h²)`

实测的机制增量：

`Cactual(α)=mean_core((F_epsilon(α)-ε_true)²)-mean_core(r0²)`

关系成立的必要条件是局部线性化在测试α处近似有效；即使 `g_h` 不为零，由于 `2α<r0,g_h>` 允许为负，`Cactual` 也不一定正或随ε单调增长。所有C值的单位为(με)²，导数g单位为με/α。

**重要限定**：`qtrue`、`ec` 以及 `r0=F(0)-εtrue` 依赖仿真真值，仅用于机理预测，不是可部署校正器。即使Cpred预测准确，依然需要研究怎样在真实辅助MZI输出中估计这个灵敏度或其可观测替代量。

## 2. 固定输入、数据源与强制约束

- 仅使用**新P2b开发种子**：散射起点 `411001001`、辅助参考 `421001001`、辅助测量 `431001001`，步长分别 `181/197/197`，12个trial。最初2次smoke就是12次正式开发样本的第1、2次，最终分母**12，不是14**。
- 原P2旧起点311/321/331百万、V7各版本已查看开发或冻结种子**全部不再用于P2b参数或性能决策**。
- α完整网格为 `[-0.10,-0.05,0,0.05,0.10,0.50,1.00]`；全部坐标需严格递增、有限；只允许原V6c物理前向与固定9-bin相位流程。
- 每个完整trial在**4种应变×7种共模幅度**的共同 `core_valid`、`static_valid`、ROI Gauge交集上评分；最低共同Core/Static各15，ROI共同有效比例≥20%，不能因误差大或真值难看就删除试次。
- 失败试次保留在12分母、`failure_id`和`failure_reason`；不对失效试次编造C值或把失败记为“预测零误差”。
- 零应变的同主信号/同坐标输出应接近零，仅为函数不变量；不推广到实际仪器噪声。
- 原参考、主探测噪声OFF、两次真实TLS扫频相同等限制均继承P1/P2，不能据此作硬件验证结论。
- P2b代码提供 `run_frozen_test`、`allow_frozen_test`、`frozen_enabled` 三重锁，任意打开立即报错。不调用/生成冻结试次。

## 3. 预定主要结局和反例

**首要研究结局：** ε=5με、α=1下，局部预测 `Cpred` 能否在12个trial上比“永远预测C=0”的空模型更准确？用每trial配对绝对误差收益定义：

`gain_i=|Cactual_i|-|Cactual_i-Cpred_i|`。

报告 `mean(gain)` 与trial级2000次bootstrap 95%CI，正值表示本模型优于零效应预测；同时报告预测误差均值、MAE、符号一致率、最坏退化、预测较好/较差次数和程序失败率。所有这些报告需先完成smoke，而**即使区间排除0也仍是开发期证据**。

**次要结局：** ε=0/1/10με及α=0.5和1的全部配对情况；中心差分h=.05与.1导数的RMS差；`2α<r0,g>`交叉项与`α²<g²>`二次项分别的符号/量级；按trial共同ROI/Gauge有效比例。

**可证伪情形：** α=0附近局部灵敏度不能预测α=.5或1、符号一致率低、模型MAE不优于零基线或极度依赖少数散射实现，说明不能将旧P2的C正增量归纳成可靠局部机制。这些负结果应留存。

未来若要做统计推断，需要扩大**完全独立开发集**并在参数锁定后使用预留的独立冻结集；本轮仅12次探索。多个ε与α属于同一trial相关重复比较，不可作为96个独立样本。

## 4. 与P1b物理离散误差保持隔离

本轮固定原V6c散射密度，不同时引入新细网格、非线性时延或新Hilbert估计器。P1b连续散射收敛尚未解决，故P2b所得灵敏度规律只能称**当前固定离散模型中的机制证据**。后续细网格/不同辅助SNR/真实平台输入需单独新协议复核。
