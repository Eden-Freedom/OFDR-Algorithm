# P2c-A：单/双延迟辅助 MZI 的光频可观测性数学审计（仅理想相位）

> 新研究分支：`research/p2c-a-aux-mzi-identifiability-20261114`。本阶段代码未在用户MATLAB实机执行，以下秩值都是**可检验的预期数学结果**，不可写成实机日志。无随机Rayleigh散射、无随机重复、无统计CI，因这是确定性线性代数例题而不是随机数值性能实验；任何后续物理实验则须恢复trial/失败率/CI/有效位置等完整科研协议。冻结测试继续被锁定。

## 1. 正确的观测方程

辅助MZI输出为相位差（在可理想获得解缠相位的强观测假设下）：

```
phi_a(t) = theta(t)-theta(t-tau) + phi0 + nphi(t)
         = 2*pi*integral_{t-tau}^{t} nu(s) ds + phi0 + nphi(t).
```

这是积分窗口，不是无条件的 `2πτν(t)`；在扫频频率变化相对τ慢时，才可以近似 `2πτν(t-τ/2)`。此外真实PD首先提供`cos(phi_a)`，Hilbert+unwrap可能有边界、幅度衰落和相位周期歧义。本数学实验先假设取得完美的解缠相位：如果该强观测模型都不可辨识，单通道原始强度观测也不可能仅凭自身消除该歧义。

以时间单元 `dt=1e-6 s` 和64个未知分段常值相对扫频频率`nu_k(Hz)`，令无量纲`x_k=nu_k*dt`（周期/格）；矩阵`A_jk`表示观测窗口`(t_j-τ,t_j]`与第k时间单元的**交叠时长/dt**。于是：

```
phi=2*pi*A*x + phi0.
```

只使用那些完整积分窗口包含在已知仿真时间区间中的`t_j`，不错误将缺失的延迟之前历史当成零。所有矩阵秩和数值零空间与实验选择的**分段常值离散模型**相关，实际连续频率形状、先验带宽和观测噪声可能改变有效可辨识性结论。

## 2. 固定示范设置（不能事后调参数挑选结论）

- 64个频率单元，dt=1微秒；辅助时延1为4微秒（4个采样格），时延2为5微秒（5个采样格），两个正整数延迟互素。
- 光频坐标使用`x=nu*dt`，是为了数值条件合理的相对扫频示范，**不是实际OFDR仪器的绝对193THz光频或正式器件参数**。
- 延迟1完整窗口61条，延迟2完整窗口60条。
- 单通道已知相位offset，检验`rank(A1)`；未知offset时，检验去掉常数方向后的`rank(P1*A1)`。
- 两条延迟已知offset，堆叠`[A1;A2]`；各自未知offset，堆叠`[P1*A1;P2*A2]`或增广矩阵`[2πA,phase_offset_columns]`。
- 所有单元测试禁止使用随机数，禁止读取V6/V7/P1/P2开发和冻结文件，不做实际应变校正或Core RMSE计算。

## 3. 预期数学性质与可证伪反例

| 观测类型 | 理论预期数值秩 | 未知光频64维中的核空间维数 | 解释 |
|---|---:|---:|---|
| 单延迟4格，常相位偏置已标定 | 61 | 3 | 4格移动积分有3个离散周期零均值盲模式 |
| 单延迟4格，未知常相位偏置 | 60 | 4 | 再失去一个绝对直流光频自由度 |
| 单延迟5格，常相位偏置已标定 | 60 | 4 | 5格的积分零模态 |
| 4格+5格，两个offset均已标定 | 64 | 0 | 该特定有限网格下联合满秩 |
| 4格+5格，各自未知offset | 63 | 1 | 联合消除4/5格特有的周期盲方向，但仍有一个共同直流规范自由度 |

当把64维光频向量和两个未知offset一起看成66维未知参数，增广`[2πA1,1,0;2πA2,0,1]`秩应为65、核空间为1维。**双延迟满秩不意味着在未知相位offset下可以测得绝对光频**。

构造三类反例：

1. **单时延盲模态**：周期4的`sin(2πk/4)`在任意4个连续完整单元内和为0；即使两个扫频轨迹都严格单调，它们可以有不同`x(t)`但完全相同的理想辅助相位。时延5的第二观测应看到差异。
2. **未知相位零点/直流规范歧义**：`x'=x+δ`，`phi0'=phi0−2π*(τ/dt)*δ`，单延迟相位完全相同；双延迟各未知offset也可各自调整同一δ。因此`ν`的绝对零点需要另一种先验/标定。
3. **未知τ与线性扫频的尺度歧义**：令`ν(t)=ν0+a t`，已知相位公式为`phi=2πτ[ν0+a(t−τ/2)]+phi0`。将`τ'`改变、`ν0'=ν0τ/τ'`、`a'=aτ/τ'`，并对`phi0'`作相应调整，可得到不同真实扫频与相同理想相位数据。这是**单延迟、未标定τ、未知相位offset、无额外端点/光学标定**条件下的反例，不是声称所有多通道或已知端点情形都不能识别τ。

补充频域理解：积分算子对光频扰动在频率f下的响应为`Hν(f)=2πτ*sinc(πτ f)*exp(-jπτ f)`（此处sinc定义`sin(x)/x`），在非零整数`f=m/τ`处出现盲频点；离散零模态是其网格化演示。必须注明有限时窗、采样、边界、噪声与先验可改变可辨识条件。

## 4. 研究目的与下一步

本数学审计的目标是清楚定义**实际辅助MZI相位究竟能辨识哪些光频误差方向**，为后续无真值SSWT/Hilbert辅助校准设定边界。它不是新的扫频校正器，不是独立物理盲测，也不应把已有延迟干涉理论包装为论文创新。

运行数学单元测试和3幅图之后，根据结果制定P2c-B计划：在规定单/双延迟与独立标定条件下，验证真正不访问`qtrue`、`epsilon_true`、`e_c=qhat-qtrue`、Oracle残差的辅助相位处理与主干涉重构。必须预注册强基线（Hilbert+unwrap、SSWT）、不同SNR/两次真实扫频漂移/时延误差，配对统计与失败分母、空间有效比例和明确冻结集。
