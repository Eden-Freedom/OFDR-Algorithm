# P2c-A2：辅助不可观测光频方向是否影响OFDR双扫描主干涉相位？

> 状态：在已通过MATLAB的P2c-A基础上新增**确定性数学反例**，尚未经用户MATLAB实机运行。原P2c-A 64维秩证据已归档至 `docs/P2CA_REAL_MATLAB_RESULTS_2026-11-15.md`。此阶段不生成Rayleigh随机样本、不计算NUFFT/Core应变RMSE、不涉及冻结测试，严禁称作已验证的应变校正方法。

## 1. 不能把辅助算子的零空间直接等同于应变误差

原P2c-A证明单4格辅助延迟有3维盲方向，双4+5格可消除周期盲模式。但有一个关键科学缺口：零空间里的光频差异 **是否影响相位敏感OFDR的测量目标**，取决于主反射/散射路径时延和双扫描差异。

对两次真实扫频的无量纲频率单元`x_r=ν_r dt`、`x_m=ν_m dt`，定义辅助观测与单点主干涉观测：
```
φ_aux,r = 2π A_aux x_r + b_aux,r
φ_aux,m = 2π A_aux x_m + b_aux,m
φ_main,r= 2π A_main x_r + b_main,r
φ_main,m= 2π A_main x_m + b_main,m
```
其中 `A_aux` 与 `A_main` 都是**真实延迟积分窗口**对应的矩阵，而不是无条件`2πτν(t)`局部近似；此纯数学示例固定两扫描的硬件偏置相同且主单反射点本身完全不变（相当于无应变/无温漂、相同回波路径）。

令未知扫描差`δx=x_m-x_r`；若
`A_aux δx=0` 而 `A_main δx≠0`，
那么两个扫描的理想辅助相位完全不可区分，主点反射干涉相位却不同。由此得出**必要的观测约束问题**，但还不能证明无法从主干涉波形或其他先验中共同估计这个误差方向。

## 2. 预设的确定性有限维例题

- 复用P2c-A固定参数：N=64, dt=1 μs, 4-bin单辅助延迟，第二延迟5-bin。
- 新的单点主反射路径延迟设为2-bin，是纯数学参数（对应精确时延积分，**不是实际OFDR FUT器件参数**）。
- 两扫描频率坐标均严格递增：
  `x_r(k)=0.25+0.05*k+0.008*sin(k/8)`；
  `x_m(k)=x_r(k)+0.01*sin(2π*k/4)`。
- `δx(k)=0.01*sin(2πk/4)` 对任意四个完整单元的和严格为0；单4-bin辅助永远看不到它。
- 但2-bin主积分窗口中相邻两个`δx`之和的绝对值为0.01周期，理论主相位差绝对最大值`2π·0.01=0.062831853 rad`。5-bin辅助延迟也应有同一最大相位量级。
- 仅对两个矩阵都具有完整延迟窗口的共同时间索引比较主和辅助相位，不把未知过去时刻填零。
- 主对照1：把主反射延迟改为4-bin，则此扰动同时属于主路径零空间，理论主相位差约为0；证明不是所有辅助盲模态都必定造成主误差。
- 主对照2：将**完全相同**的盲模态加到两次真实扫描，主点反射的双扫描相位差应为0；证明共同扰动有可能被差分抵消。
- 主对照3：给两扫描共同增加常频率偏置0.03周期/格，双扫描主相位差保持不变；不能把“绝对光频零点不可辨识”直接等同于“相位敏感应变必然有误差”。

## 4. 科研结论的上限

如果演示成功，只能证明**在这个确定性点反射和理想相位模型下，存在辅助无法看到但主相位受影响的扫描差异**，而不能证明实际分布式Rayleigh应变恢复一定出现多少με误差。真实OFDR还可能通过主信号与其他先验联合估计盲方向；频率误差在空间回波的影响取决于光程延迟、散射分布、NUFFT/重采样和双扫描配准。

下一阶段研究关口才是：受约束的辅助-only校准与辅助+主参考段联合观测的**可辨识性和下游敏感性**，在无真值输入条件下评价各自的不可观测子空间；之后才考虑Hilbert与SSWT对比及真正随机相位敏感OFDR指标。

相关已知理论背景：光纤延迟鉴频器的`sinc`零点和有噪声的延迟响应，见Optics Express `https://doi.org/10.1364/OE.569203`；OFDR辅助频率校准及绝对光频参考的重要性见 `https://pmc.ncbi.nlm.nih.gov/articles/PMC11359119/`。本研究不声称延迟积分零点本身是新发现。
