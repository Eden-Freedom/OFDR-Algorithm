# P2c 研究关口草案：从真值辅助灵敏度预测转向辅助 MZI 可观测性

> 状态：**仅研究方案，未实现、未运行、未冻结**。此文件记录 P2b 12/12 开发集之后的优先级变化，不更改已观察的 P2b 数据及正式主指标。不得自动调用现有V7冻结集。

## 1. 为什么不继续做更多固定模型下的α网格测试？

P2b已验证：在相同参考和测量真实TLS轨迹、主探测器无噪声、原V6c固定离散散射模型条件下，沿**已知**共模误差方向 `e_c` 对 `F_epsilon(α)` 作一阶泰勒展开，能以很小的误差预测未用于计算导数的α=.5和1上的MSE增量。主终点（5με α=1）模型MAE为8.6993841e-5με²，零效应基线MAE为0.014795715με²。

**数学平滑性与算法创新必须严格分开**：对给定光频误差方向及已知真值，平滑映射的局部线性化表现良好并不自动构成新的OFDR扫频校正方法。原预测器依赖 `qtrue`、`e_c=qhat_avg-qtrue` 和 `r0=epshat_oracle-eps_true`，这些输入在实际测量时不可直接使用。继续在同一条件下扩大trial只能进一步量化这条Taylor近似的稳定性，无法解决核心的可部署性障碍。

## 2. 辅助 MZI 观测的正演模型与不可辨识自由度

理想单延迟辅助MZI观测到的是两条光路瞬时光学相位的差。设瞬时光频为ν(t)、激光光学相位满足 `dθ/dt=2πν(t)`，则在固定群时延τ_a的简化模型中：

`phi_a(t)=θ(t)-θ(t-τ_a)+phi_offset+n_phi(t)
         =2π∫_[t-τ_a]^t ν(s)ds+phi_offset+n_phi(t)`

其中`phi_offset`可能由固定路径相位、检测参考相位等贡献；`n_phi`为实际估计噪声或模型残差。只有在扫频频率变化相对于τ_a足够平滑时，才能近似 `phi_a(t)≈2πτ_a ν(t-τ_a/2)+phi_offset`；不能无条件用`2πτ_aν(t)`替代积分。

从单条`phi_a(t)`数据直接恢复`ν_true(t)`可能存在：
- 未知常相位或光频零点：若只获得相对解缠相位，光频的固定零偏可能与相位截距混淆；
- 未知或漂移的时延τ_a：一阶近似中`ν`的尺度与`τ_a`相互耦合；辅助延迟须经独立标定或引入更多约束；
- 单延迟积分算子的条件数/盲频率方向及有限带宽、噪声、相位解缠错误；
- 两次真实TLS扫频不完全相同时，参考/测量轨迹的共有/差异并不能简单从单一扫描处理得到。

这些是要分析的**条件性模型不辨识风险**，目前不是对现有代码或实际仪器已证实的普适定理。应从离散化物理前向雅可比矩阵的秩、奇异值和规定的先验/标定条件开展可检验分析。

## 3. 强制输入边界：未来候选必须无真值

候选实际校正器只允许读取：
- 两次辅助干涉仪时域测量波形与已知/独立标定的辅助延迟；
- 参考与测量主干涉原始采样波形；
- 经事先声明的静态参考段观测及采样/硬件标定信息。

**禁止**：`qtrue`、`epsilon_true`、`e_c=qhat-qtrue`、Oracle重构的`r0`、用实际Core真值来选择α/步长/权重/门控。Oracle仅用于机理注入和独立评分。静态段若需作为校正器输入，则不能在评分时对其进行专用过拟合而把结果当成未知区域精度。

应明确区分**可观测光频轨迹的形状/相对变化**、绝对尺度、两扫描相对配准、时延与空间应变实际尺度；若某自由度无观测约束，需给出不能识别的反例而非自动引入真值。

## 4. 建议的新研究问题（按先后顺序）

### P2c-A：仅数学可辨识性审计（先不增加随机试次）
1. 为单辅助MZI的相位积分正演建立离散矩阵`H(τ_a)`，求其奇异值与受观测时窗限制的近零模式；
2. 加入未知相位offset、未知τ_a、两次扫描漂移时的雅可比矩阵，分析秩缺失和信息界；
3. 严格区分“允许独立测得τ_a/扫频端点”与“不允许任何外部标定”的不同识别问题；
4. 在纯合成无噪声例子中展示一组不可区分的参数或病态方向，并用独立标定说明如何消除该歧义；
5. 形成可证伪的结论：哪些共模误差方向可以从辅助波形恢复，哪些必须通过静态段/外部仪器/第二延迟通道提供信息。

### P2c-B：强基线的无真值算法比较（需新协议和新开发种子）
- 直接辅助相位 Hilbert+unwrap（显式报告带通/边缘处理），与SSWT轨迹估计、静态仿射归一化、必要的双扫描轨迹配准比较；
- 保证所有算法拥有**同样可用的先验/参考段**，不允许一个方法获得真值坐标或真实应变；
- 应变Core RMSE、Holdout静态伪应变RMS、失败率与固定ROI有效覆盖率作为联合结果，不只考察辅助相位拟合误差；
- 观测变化：辅助SNR，真实双扫描范围/速率漂移，τ_a标定偏差，主探测器噪声，Rayleigh散射密度/衰落，空间边缘响应；
- 预先固定条件网格、主比较、配对trial级CI与报告所有失败，不从已查看开发/冻结数据中筛选有利条件。
- 若基线已经达到理论可辨识上限或没有新增可测信息，则应明确终止“新校正方法”主张，转向边界/不确定度分析。

## 5. 另一个必须保留的独立工作：P1b
4个耦合散射实现显示1.5mm与0.375mm Oracle RMSE有可见差异，0.75与0.375mm的配对CI跨零；**尚未证明物理前向模型对连续Rayleigh随机场收敛**。任何P2c物理推广都必须保留对散射网格、PSF和应变边缘10–90%响应的敏感性评估。

先以只读工具对12个已保存trial审查Oracle交叉项`2α<r0,g>`与二次项`α²<g²>`作用、最坏预测误差、相对h差、试次级预测误差及探索性更强的基线。**不能改变P2b的预先指定主终点或原Bootstrap CI**。
