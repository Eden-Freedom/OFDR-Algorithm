# P2b 共模坐标误差的局部灵敏度预测：未来研究设计草案

> 仅供下一阶段设计；**尚未实现/冻结/运行**，不属于当前P1c数值审计的实机结论。旧P2开发种子[311001001,...]已经查看，不再用作独立模型验证。新算法/统计冻结须在P1c质量审查之后另立分支与版本。

## 1. 已观察结果

原P2在同一物理主信号下定义两辅助坐标误差 `e_r`、`e_m`，共模 `e_c=(e_r+e_m)/2`、差模 `e_d=e_m-e_r`。开发n=8时，仅共模相对Oracle的MSE增量C在0με为0，在1/5/10με分别是+0.0052708/+0.018078/+0.017510με²，且每个非零水平8/8为正、trial-bootstrap 95%CI不跨零。1με处2×2交互项I的单项探索性CI全负，而5/10με跨零。n小且无多重校正，不推断稳定泛化。

## 2. 需要预测、可证伪的数学关系

定义固定应变ε、固定散射实现下的输出向量（不是单一RMSE）：

`F_epsilon(alpha,z)=D( R(s_ref,q_true+alpha*e_c), R(s_meas(epsilon),q_true+alpha*e_c) )_z`。

`alpha`是共模误差方向的无量纲扰动幅度，`e_c`固定为该trial的辅助估计误差方向（Hz）。这与旧P2的00/10严格相接：alpha=0即00，alpha=1即10。真值q_true和e_c只用于因果机制注入，**不得作为可部署校正器输入**。

在alpha=0附近，作方向导数：

`g_epsilon(z) = dF_epsilon(alpha,z)/dalpha |_(alpha=0)`。

用预先固定的中心差分h估计 `g≈[F(+h)-F(-h)]/(2h)`，再以不同的h检查局部线性近似是否稳定。固定Core真值误差 `r0(z)=F(0,z)-epsilon_true(z)`，得到只基于局部一阶预测的平方误差增量：

`C_pred(alpha)=2*alpha*mean_core(r0.*g)+alpha^2*mean_core(g.^2)`。

实测机制增量是 `C_actual(alpha)=MSE(F(alpha),truth)-MSE(F(0),truth)`。

**可证伪重点**：由alpha接近0的局部导数能否预测未用于求导的alpha=0.5与alpha=1的C值/符号；应变越大时方向导数是否非线性，零应变是否始终不变，哪些散射实现具有巨大局部不稳定性。

上式不仅有非负平方项，也有 `2*alpha*mean(r0.*g)` 的交叉项，因此即使共模局部影响 `g` 很明显，也不能仅凭C(ε)均值推断 `C∝ε²`。现有5和10με的C近似相等不能直接解释成灵敏度饱和，必须检验这个混合误差项。

## 3. 拟预先约束的实验控制

- P1c的NUDFT-Gauge数值核验是前置闸门；如它未排除数值近似问题，先修P1，而不直接拟合灵敏度。
- 未来新分支、新种子、新协议；固定真实物理扫频、散射结构、时序、时延、窗口与Gauge方式，每个trial所有alpha和ε共用同一物理主信号，并在预设的全组共同Core有效位置上评分。
- 在正式开发/冻结前预定差分步长（建议候选预案h=0.1与0.05）、待验证α=0.5/1、应变集合及逐trial失败处理，**不根据Core真值选择哪一个h更显著**。
- 每个扰动坐标必须有限且严格单调，不可通过Oracle评价删除不利trial；失败保留分母，报告全部空间有效率。
- 以完整独立散射+噪声trial为bootstrap单位，给出预测与实际C的配对误差、符号一致率、预测相对误差、最差失配和失败率；不把同一trial的多应变视为独立随机样本。
- 在真正独立的应变/误差幅度条件上评估外推，不将已经看过的P2开发8试次重新命名为盲测。

## 4. 退出条件与论文边界

若在数值可靠的前提下，方向导数预测跨试次高度不稳定、对步长与Gauge平均极端敏感、或不能预测预留应变下的C幅度，保留负结果并分析物理模型/散射相关性。不因为C为正就自动宣称产生了新的校正算法。只有将共模灵敏度映射到真实辅助MZI可以估计的量，并与Hilbert/SEFR/其他强基线公平比较，才考虑提出可部署方法和后续论文贡献。
