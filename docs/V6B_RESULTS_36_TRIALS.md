# V6b 本地 36 次重复结果：已观察到什么，尚未证实什么？

> 数据来源：使用者在 MATLAB 中设置 `repeats=36` 和 `sswt_repeats=36` 后提供的 2026-11-13 命令行及五幅图。本文件不重新生成数据，也不将图中近似读数伪称为精确 CSV 值。

真实独立 SSWT：36/36 有效；等效虚假应变代理均值 0.58975 με，bootstrap CI [0.5694, 0.6076] με。该组未强制两次单扫 RMS 相等，不能直接与上表中的注入误差看作相同输入条件。

实际独立 SSWT 差分残差的单次消融：加权比例斜率 −2.577 ppm、去仿射残差 RMS 0.3232 MHz。Figure 3 中非线性-only 的相位/应变误差接近 full-difference，而 ramp-only 小很多；**该分量消融仅有一组示例**。

## 2. 五幅图分别支持什么？

- **Figure 1**：在同一个 trial 的相同散射体、共同有效 gauge 掩码下，ρ 增大、扫描间误差变小、gauge 相位 RMS 同时下降。ρ=0 与 ρ=0.9 的代理 RMS 均值比约 2.84；这是重复性机制证据，尚不是可用校正方法。
- **Figure 2**：Gauge 相位与总差分光频 RMSE 相关；与加权去仿射残差 RMS 的散点看起来更集中。要声称后者更有预测力，必须在新数据上比较线性/非线性拟合的 out-of-sample R² 和残差分布，不能靠目测。
- **Figure 3**：当前配对 SSWT 示例的锚定非线性分量引发的相位误差远大于锚定 ramp。这不意味着比例误差永远不重要：测距偏差与静态场景有关，也要看距离和 gauge。
- **Figure 4**：在同一组 ρ=0 错误下，gauge 相位 RMS 随距离段中心整体上升，gauge 长度的影响并非单调；有效位置比例约 82%–92%。应变代理的 gauge 长度归一化也会改变趋势，不能用相位 RMS 单独代表应变 RMSE。
- **Figure 5**：真实独立 SSWT 的参考/测量单扫 RMSE 不被强制相等，个别试次出现高于平均的校准残差；报告均值与尾部分布、以及与低幅度 dropout 的关系，不能只挑选平均最好的随机种子。

## 3. 需要保护的结论边界

- 所有结果均为**零应变等效虚假应变代理**，尚不能与真实加载精度比较。
- 36 个 trial 是独立随机实现，沿光纤上高度相关的 gauge 像素不是独立重复。
- 改变 ρ 的同时也改变了差分 RMSE，因此**ρ 与误差强度的独立因果作用尚未识别**。
- 只做了简单标量散射体、同真实扫频、无主噪声，没有温度/偏振/随机扫频起终点偏移。
- “去仿射残差更强”需要跨 seed 消融或匹配同等 RMS 的对照，当前只是一条建议研究的线索。

## 4. V6c 的具体决策门槛

1. 用物理位移+载波弹光相位重新生成受应变测量主信号，而不是在未受应变重构谱上直接加理想相位。
2. oracle/oracle 先恢复已知 1/2/5/10/20 με 的平均值和符号；并报告 oracle 自身衰落噪声底限。
3. 同一物理信号下检验独立 SSWT 相比 oracle 的额外 RMSE，不能把两者混成“SSWT 误差”。
4. 同时报告静止区假应变 RMS、幅度门限有效率、raw 与复相位平均的空间支持差别。
5. 只有当 oracle 已可靠、SSWT 的新增误差可重复，才进入候选相位保真校准算法。
