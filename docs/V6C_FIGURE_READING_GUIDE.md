# V6c 图像阅读指南：哪些曲线真正说明“应变准确度”？

所有表述必须参照 [V6C 实验指南](V6C_EXPERIMENT_GUIDE.md) 的物理假设和约定。**在本轮 MATLAB 本地验收前，下面描述的是图像设计和判定规则，不是已获实测结果。**

## Figure 1：单个已知 5 με 的空间应变恢复

- **问题**：参考扫描/受应变扫描确实不同后，Gauge 相位差能否恢复形变？校准误差会在哪里污染应变？
- **横轴**：Gauge 中心位置 m；**纵轴上**：Recovered gauge strain (με)，**下**：应变估计减去真值 (με)。
- **黑线**：已知材料应变场经过实际 gauge 长度积分后的真值，不等于原始方波（边缘被 gauge 平均）。
- **彩色线**：真实坐标 oracle、共模 SSWT、独立 SSWT。发生相干衰落位置由 NaN/断线表示，不得补零使曲线变好。
- **第一眼**：应变平台 [1.08,1.62]m 的中部，oracle 是否靠近 5 με？两端过渡是否与黑线方向一致？静止区是否回到 0？
- **准确读数**：`metrics.core_true_mean_microeps`、`metrics.core_measured_mean_microeps`、`metrics.core_strain_rmse_microeps`、`metrics.static_false_strain_rmse_microeps`、`metrics.valid_fraction`。
- **什么结论成立**：oracle 恢复了已知非零应变的量值和符号；SSWT 是否增加了应变误差。
- **什么不能说**：这是实验室真实加载光纤的精度；本代码仍是近似物理仿真。

## Figure 2：已知输入 vs 恢复值，以及 RMSE

- **问题**：相位换算系数是否正确？误差是否随加载应变增长？
- **横轴**：已施加平台应变 0/1/2/5/10/20 με。
- **上图纵轴**：中部平台平均恢复应变 με；黑色 y=x 是理想灵敏度。
- **下图纵轴**：中部平台区域对**已知 gauge 平均应变真值**的 RMSE με，**不是**和 oracle 结果相比的 RMS。
- **读取数值**：CSV 的 core_truth/core_measured/core_rmse 字段；同时读取 `valid` 和 `failure_reason`，不能把失败当零。
- **判断**：如果 oracle 本身偏离 y=x，优先排查模型或相位解调（载波相位、群时延、空间方向、相位包裹等）；不可将异常归因于 SSWT。
- **创新联系**：只有 oracle 通过以后，SSWT 相比 oracle 的**边际恶化**才有校准算法改进的意义。

## Figure 3：静止区“虚假应变”与有效位置比例

- **问题**：受应变区外被错误测成应变了吗？是否通过排除低幅度位置人为得到低 RMSE？
- **横轴**：真实加载应变 με。
- **上图纵轴**：不受应变区（距离加载区边界至少 50mm）的虚假应变 RMS με；越低越好，**但不能单独看这一项**。
- **下图纵轴**：通过幅度门限的可用 gauge 位置百分比，越高越好。
- **判断**：共同算法改进需要在误差降低的同时不大幅牺牲有效率；静止区虚假应变上升可能来自校准差异，也可能是 Rayleigh/解调器物理噪声底限，应与 oracle 对照。

## Figure 4（启用 run_mc 后）：多随机实现的重复性

- **问题**：某一条散射体实现上的“准确”是否只是巧合？
- **横轴**：trial 编号；上图两条曲线是 oracle / independent SSWT 核心区应变 RMSE；下图是有效率。
- **统计单位**：每次重新生成散射体+独立辅助噪声的一整对扫描。**不能**将沿光纤的几千个 gauge 点当作独立重复。
- **应当补充**：均值/中位数/P95、失败率、成对算法差值的置信区间；如果 SSWT 没有稳定恶化且 oracle 也达不到目标，研究结论应调整。

## 重点警示：原始 gauge 和复邻域平均结果必须分别报告

V6c 默认用 `phase_avg_bins=9` 对 9 个相邻**复数 gauge phasor**做平均再取角度，以缓解 Rayleigh 相干衰落；同时保留：

- `core_raw_strain_rmse_microeps`：不加空间平均，继承 V6a 的原始差分方法；
- `core_strain_rmse_microeps`：明确加入局部平均后的误差；
- `effective_spatial_support_m`：所报告误差背后的有效空间支持尺度。

在当前约 0.818mm 的距离采样网格、约 9.813mm gauge、9 bin 平均下，支持尺度约 16.36mm。空间平均不能免费获得精度，必须与分辨率一起讨论；不同平均窗长度的结果不能横向当成相同空间分辨率的算法性能。

## 论文研究记录模板

每张图写清楚：（1）可证伪的假设；（2）物理真值/控制变量；（3）横纵轴、单位与量测长度；（4）oracle 和实际算法的精确定义；（5）失败/无效样本比例；（6）可以和不可以支持的科学结论；（7）与现有工作差异及下一步实验。

**最终目标指标**：在相同相位量测算法、相同空间支持、相同 SNR/失效率与同一散射实现上，候选校正方法相对原始 SSWT+NUFFT 的**非零应变 RMSE 下降及静止区假应变降低**；仅凭单扫描光频 RMSE 下降不能认定论文创新成立。
