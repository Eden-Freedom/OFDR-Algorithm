# V6d 逐图阅读指南

## Figure 1：四类误差的非零应变影响

- **问题**：坡度和非仿射残差哪个对真实应变误差贡献更大？
- **上图横轴**：no diff、ramp、nonlinear、full。**纵轴**：已知应变 core 区 RMSE (με)，误差棒为独立 trial 上的 95% bootstrap CI。
- **下图**：同组的静止区虚假应变 RMS (με) 与 gauge 相位误差 RMS (rad)，**单位不同，不能仅凭柱高对比两者数值大小**。
- **正确比较**：在同一组共用有效位置下比较 `nonlinear_only` vs `ramp_only` 和 `full_diff`。将 `full_diff` 视为实际独立 SSWT 的参考，而不是理想无误差 reference。
- **不能得出**：直接用上述真值分解实现实际校正，或认定低 core RMSE 就意味着静态误差也更小。

## Figure 2：逐 trial 配对散点

- **上图横轴**：完整差分 core RMSE (με)；**纵轴**：非仿射分量独立注入时的 core RMSE (με)。对角线表示两者相等。
- **每个点**：一次独立散射体与辅助噪声种子配对，而不是一个空间像素。
- **下图横轴**：拟合的比例斜率 (ppm)；**纵轴**：非仿射残差加权 RMSE (MHz)。用于检查误差结构跨 trial 的变化。
- **关键看**：点是否稳定落在对角线附近；非仿射分量主导是否是大多数 trial 的现象，或只在部分随机实现成立。
- **注意**：即便非仿射残差统计显著，也没有证明只有非仿射残差可校正，必须下一步使用不含真值的可观测算法。

## 论文结论门槛

报告成功 trial 数、有效 gauge 比例、实际 gauge 长度与空间平均支持尺度；配对比较 CI 若跨越 0，则不应宣传强机制结论。V6d 是**误差机制**，V7 是**可实现校正器原型**，两者不可混同。
