# V7b MATLAB 实测结果：100 次冻结盲测与 17 组物理条件扫描

**数据来源**：用户于 2026-11-13 提供的 MATLAB 控制台输出与 Figure 1–3。本文只登记用户实际提供的数据；未运行 MATLAB 重算原始试次。

## 1. 冻结参数独立种子盲测（100/100 成功）

| 方法 | Core RMSE 均值 (με) |
|---|---:|
| Oracle | 0.1122 |
| Raw Independent SSWT | 0.2231 |
| Static affine | 0.2187 |
| Full SAPC | 0.2152 |

- Full SAPC vs Raw SSWT：Core 配对改善 **0.007898 με**，95% bootstrap CI **[0.005408,0.010496] με**，持出静止区改善 **0.014456 με**，CI **[0.009989,0.019359] με**；有效率差 **+0.007 个百分点**。
- Full SAPC vs Static affine：Core 配对改善 **0.003482 με**，CI **[0.001994,0.005146] με**；持出静止区改善 **0.006594 με**，CI **[0.003756,0.009199] με**；有效率差 **−0.010 个百分点**。
- 相对 Static affine：**65/100** 次 Core 改善，**35/100** 次退化，最差退化 **0.014447 με**。
- 这表明 SAPC 在本次固定仿真条件下具有平均小幅收益，但**35% 退化率**值得专门研究；统计显著不等于工程上具有足够的性能优势。
- Figure 2 的训练区相位改善 vs 持出 Core 改善散点并非单调：训练误差变小不保证核心应变精度提高。
- Figure 3 未正则化 Hessian rcond 与收益的散点图只提供**观察性关联**；不能从这些散点直接推出 Hessian 条件数是退化的因果原因。

## 3. 由数据提出的 V7c 可证伪假设

> 如果上游静态段内的未参与拟合的空间验证区域不支持非仿射修正，退回稳健的 Static affine 可能减少 SAPC 的部分退化；若验证区确有可靠改善，则保留或部分采用非仿射修正。

这只是**模型开发假设**，不是 V7b 结果本身已经证明的结论。后续 V7c 新的空间交叉验证、门控与种子须与这批历史数据分离；V7b 的 100 次样本不再用于计算 V7c 的独立置信区间。
