# V7c 算法冻结与独立验证协议（项目内部）

**Protocol**：`V7C_CV_SAPC_2026-11-13_B`。记录目的：说明在尚无 MATLAB V7c 结果时，算法规则、随机种子、主次指标和否决条件。该文件不是第三方注册，也不能证明论文新颖性。

## 一、研究假设与基线

H1：已知上游静止区内部的空间阻塞交叉验证可以拒绝部分过校正，使 **CV-SAPC** 对 **Static affine** 的失效风险更可控。
H2：CV-SAPC 在新种子的受应变区域 Core RMSE 及下游未训练静止区 RMS 上，至少与 Full SAPC 同样稳健；若 CI95 跨 0 或下降，假设不得宣称成立。

独立比较六方法：Oracle（仅评分）、原始 SSWT、Smoothed SSWT、Static affine、Full SAPC、**CV-SAPC**。前五种配置沿用 V7/V7b，不重新调参。每个 trial 所有方法共用 Rayleigh 散射实现、两条辅助信号与主干涉信号，使用共同有效 gauge 位置评分。

## 二、固定算法规则（在测试前决定）

- 原 Full SAPC 的四个基函数：`[x,x(1-x),sin(2πx),sin(4πx)]`；Affine 用 `x`。
- 原 V7 的正则化 `2e-5`、4 次阻尼 GN、频率差分 `0.5 MHz`、最大修正 `5 MHz`、训练 stride=3、phase_avg_bins=9；**保持不变**。
- 已知上游静止段默认 `[0.55,0.98] m`，下游持出静止段 `[1.78,2.23] m`、应变区 `[1.08,1.62] m`，5 με 平台、10 mm 约定 gauge、主探测噪声关。
- 在上游训练段内预先留出两个区块：相对区间 **[0.18,0.34]** 和 **[0.65,0.81]**；留出区两侧有 **25 mm 保护带**。两折分别在剩余区拟合并在留出区评估，均使用训练区的实际复 gauge 相位。**不能**读取受应变段、下游静止段或真实光频计算门控。
- 候选非仿射混合系数 `α∈{0,0.25,0.5,0.75,1}`，其中 α=0 表示直接采用仿射校正；其他值为 `q_affine+α(q_full−q_affine)`。使用独立训练子集拟合的 affine/full 计算留出区相位 RMS，聚合两折最小化分数。
- 当相对于 α=0 的留出区相位 RMS 改善**至少 1.5% 且至少 1e-5 rad**，Full SAPC 的未正则化数据 Hessian `rcond>=3e-5`、Jacobian 满秩、额外非仿射峰值修正 ≤0.8 MHz、全部轨迹单调时，才启用 α>0。否则 **α=0** 并记录回退原因。算法可能把有益修正拒绝掉，这需要外部验证。
- CV 的训练/验证数据仍来自同一根光纤、共享 NUFFT 点扩散响应，因而**不能作为真正独立数据集**；训练块与验证块之间设置保护带只能减轻空间泄漏，无法消除全部相关性。真正独立测试单位仍是全新一次试次。

## 三、完全隔离的种子与工作阶段

- V7b 历史盲测已经被查看，**禁止**用它重新优化 V7c 的门控参数。
- **开发集**：散射/参考辅助/测量辅助种子分别从 `41001001/51001001/61001001` 开始，24 次，步长 149/163；允许诊断，不可称作独立盲测。
- **冻结测试**：与开发及 V7b 不重合的种子 `71001001/81001001/91001001`，100 次；只允许在代码静态检查、开发自检完成且冻结规则记录后显式开启。运行后不可对同一 100 次调门控后再次当盲测。
- **条件扫描**：独立于主试次使用开发 seed base 加 `k*100000` 种子偏移，每组12次为初步技术预览。条件之间不做混合均值，不据此进行主盲测阈值调参。
- 需要更改模型或阈值，必须记录 **V7d 新协议和新种子**；如果修复明确程序 bug，则使受影响的结果失效并重新在新种子上测试。

## 四、主指标和成败标准

**主对照：CV-SAPC vs Static affine**，次对照 CV-SAPC vs Full SAPC / Raw SSWT。

每个对照使用 trial 为单位的配对 bootstrap（2000 次），分别输出 Core RMSE 改善与下游静止 Holdout RMS 改善的 95% CI。记录有效 Gauge 差、失败率、改善/退化次数、最差退化、回退频率与 α 分布。

“成功”需要**联合满足**：
1. vs Static affine：Core 平均改善配对 CI 下界 >0；
2. vs Static affine：Holdout 平均改善配对 CI 下界 >0；
3. vs affine：Gauge 有效比例平均下降不超过 0.5 个百分点；
4. 不忽略任何优化失败和被判无效的 trial，且报告最差退化；
5. 相比 Full SAPC 的减少退化/改进可靠性需要**独立评价**，不预设一定成立。

若 CV-SAPC 只是退回 affine 而相对 full 没有改进，也不能声称自适应结构带来新的有效性能优势。成功也不意味着实际 OFDR 仪器验证完成。
