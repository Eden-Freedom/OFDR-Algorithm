# V7d 开发数据勘误：ROI 口径与门控暴露（2026-11-14）

> 来源：用户提供的《2026-11-14 研究评估-OFDR-report.md》及仓库已有 `matlab/research_audit_20261114.m`、JSON 和 MAT。以下为**历史观察数据的只读复核**；不修改已提交的V7d代码、掩码、门限或历史原始结果。

## 1. 原结论中需要撤回的部分

原V7d开发记录将 `mean_common_valid=0.4848` 与各算法独立有效率约0.90比较，认为七方法交集损失近半测点。两者不是同一个分母：`v7d_run_trial` 的共同有效比例使用整个重构网格Gauge数，`v6c_demodulate_strain` 的单方法有效比例使用ROI中点Gauge数。因此不能据此认定交集严重损失。

| 指标 | 历史评估报告的复核数值 |
|---|---:|
| 全网格Gauge总数 | 4085 |
| ROI中点Gauge数 | 2201 |
| ROI两端在范围内的Gauge数 | 2189 |
| 24次平均共同有效Gauge数 | 1980.542 |
| 全网格分母共同有效率 | 48.4833% |
| ROI中点分母共同有效率 | **89.9837%** |
| ROI两端合法分母共同有效率 | 90.4770% |
| Affine ROI中点有效率 | 90.8697% |

因此用同一个ROI中点分母比较时，交集相对Affine的额外有效率损失约0.886个百分点，**不是近半测点损失**。历史方法已经在共同有效位置评分，Core/Holdout RMSE与配对收益不需因本勘误重算。

**另一个边界**：原文称V7d新增约束完全未作用也过强。24次完整拟合都没有E>0.8MHz，但报告指出Trial 8折内合法非仿射候选由4个减少到3个，尽管最终仍选择alpha=0.5。因此准确结论是：完整修正提前拒绝没有触发，折内候选集合在至少一个试次改变，但最终输出在24/24试次均与V7c一致。
