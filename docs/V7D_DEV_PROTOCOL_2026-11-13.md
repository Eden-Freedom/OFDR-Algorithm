# V7d-PF 开发期预设协议（非第三方预注册）
 
**协议ID：** `V7D_PF_DEV_2026-11-13_A`。本文件在用户运行V7d开发集前形成。它冻结**当前开发期的方法定义**，但独立冻结盲测仍被程序锁定，尚未开展。
 
## 1. 研究问题与因果消融
 
V7c 24次开发（已查看）中，Trial19的完整新增非仿射修正峰值 E=0.852542 MHz，略高于0.8 MHz硬限幅，导致CV之前回退Affine，事后Full SAPC改善Core 0.033498 με、Holdout 0.097 με。V7c有其他12次回退，不可全部归因该规则。
 
**H1（未验证）**：逐候选可行性过滤在不改变原CV评分与置信度规则时，可减少因完整模型超限造成的无谓回退，同时不显著增加Core/Holdout退化风险。
 
**H0**：改变约束方式后，七方法共同有效位置上的配对Core和Holdout增益没有稳定正提升，或者尾部退化更严重。
 
**重要限制**：不提出或调整新的SNR、相位可信度、Rayleigh模型、正则化方案；后者属于未来独立V7d2研究，不纳入本次因果消融。
 
## 2. 保持不变的物理模型与估计核
 
- 原V7/V7b：4个SAPC基函数、阻尼Gauss-Newton、正则化2e-5、4次迭代、0.5 MHz有限差分、训练stride=3、9点复Gauge平均。
- 与V7c相同的固定物理TLS扫频、两条独立辅助MZI估计、相同的Rayleigh散射体与受应变几何；参考/测量真实TLS轨迹相同；主探测器噪声关闭。
- 上游已知静止区[0.55,0.98]m；下游仅评价Holdout[1.78,2.23]m；应变区[1.08,1.62]m，平台5με。
- 两折空间阻塞验证[0.18,0.34]、[0.65,0.81]（训练静止段相对比例），各留出区两侧25mm保护带；每折用原来的幅度掩码、stride、有效Gauge数；仍保留潜在的转导式幅度掩码信息共享，未来需审计。
- α网格仍为[0,.25,.5,.75,1]；进入非仿射需相对α=0的验证相位RMS至少减少1.5%且绝对至少1e-5rad；full及fold的Jacobian秩≥4，数据Hessian rcond≥3e-5。
 
## 3. 唯一目标性改变：从Full预否决到逐候选可行性
 
定义 qA、qS 为基于已知上游静止段求得的Affine、Full SAPC坐标，q0为测量辅助SSWT估计。
 
对于每个alpha，qalpha=qA+alpha(qS-qA)，检查：
 
1. 全段的额外修正峰值 max|alpha(qS-qA)|≤0.8 MHz；
2. 全段相对q0的总修正峰值 max|qalpha-q0|≤5 MHz；
3. 全段qalpha严格单调、全坐标有限；
4. 每个CV折从该折独立训练子集获得 qA_fold、qS_fold，对 qalpha_fold 用完全相同三条可行性约束检查；
5. 任一折或全段不合格的alpha，该候选分数置Inf（**不归零、不把整个试次视为改善**）；只比较各折均合法且有有限相位评分的候选。
 
α=0作为基线；若基线不可行，视为程序/试次失败，不伪造成功。若没有非零候选满足条件则回退α=0。未正则Hessian/rank不通过仍回退α=0。用原来的折内复Gauge相位RMS做CV评分并沿用原1.5%/1e-5rad信任门限。
 
原V7c的CV作为**完全不改的第六种方法**；在同一trial中对第七种V7d-PF重新判定α。全段计算得到新α后重新检查坐标可行性；若出现逻辑不一致，标记该trial失败而非静默修正。
 
Oracle真实q(t)、应变几何、Rayleigh系数真值、Core/Holdout评分均**不进入拟合或alpha选择**。仿真truth中的固定标称带宽用于统一距离网格，不是借用随机实际扫频误差的真值用于校正。
 
## 4. 统计与随机种子制度
 
开发集：散射、参考辅助噪声、测量辅助噪声分别以[111001001,121001001,131001001]为基种子，逐trial步长[149,163,163]，拟做24次。Smoke用最前2次，因此正式开发样本**是24而非26**。
 
预留独立冻结集基种子[211001001,221001001,231001001]，但是**本版本 `run_frozen_test` 与 `allow_frozen_test` 一旦为true，v7d_assert_protocol立刻报错，且v7d_run_trials只允许开发集**。禁止提前使用保留种子、禁止根据开发集为同一方法多次挑选冻结阈值。
 
主指标：第七方法V7d-PF对第六方法冻结V7c的Core RMSE配对均值改善/95% trial bootstrap CI；次指标对Affine和Full SAPC，以及下游Holdout RMS。继续报告Raw SSWT；Oracle仅理想评分。Core/Holdout使用**七方法共同有效Gauge掩码**，与历史V7c的六方法均值数值不可直接横向比较。
 
附加指标：全部失败次数与原因、有效位置比例与差、α分布、决策改变数、最差退化、退化次数、平均退化、CV分数缺失原因、满修正峰值E及真正有效候选比例。
 
计算2000次trial级配对bootstrap；**禁止**把相邻Gauge当独立试次。2次smoke的CI不作显著性解释。
