# V7d 研究设计草案：逐候选可行性与相位泛化可信度（尚未冻结、尚未实现）

> **性质：研究假设，不是已验证算法，也不是已完成预注册。** 起点是 V7c 的已查看开发集和 Trial19 的只读审计。V7b 已查看盲测集不得重新用于调参；V7c 现有冻结种子不能因新方法反复用于选择超参。不要在此草案下运行任何 100 次冻结测试。

## 1. 已确认的事实与未确认的问题

- V7c 24/24 开发试次成功；alpha=[0,0.25,0.5,0.75,1] 的计数 [13,0,2,1,8]；相对 Static affine 和 Full SAPC 的 Core/Holdout 优势未得到开发集的配对 CI 支持。
- Trial19 的完整额外修正 E=0.852542 MHz，高于预注册 L=0.8 MHz 约6.57%；因原规则在CV前提前 return，alpha=0，CV分数NaN；Full SAPC相对 affine 的开发集事后 Core gain 0.033498 με、Holdout gain 0.097000 με。
- 仅一个开发试次因 E 超限而提前拒绝；另外的回退与接受失效无法归咎于这一个门限，必须另外研究CV分数外推失效。
- 对某个混合权重，E_alpha=alpha*E。候选alpha=0.25、0.5、0.75在Trial19满足单项额外幅度约束，但其单调性、总校正幅度、fold CV相位和真实应变精度**未知**。

## 2. 拟检验的研究假设

**H1：** 候选级可行性门控会避免“完整SAPC超限但部分混合仍可行”的过度回退；能否减少真实Core/Holdout错误回退，需要全新开发/测试试次的配对验证。

**H2：** 上游内部CV相位 RMS 与受应变Core误差存在条件性失配；仅降低静态相位可能不足以预测真实Core收益。需要独立建立可观测的可信度指标，并明确其适用条件，不可从开发真值直接拟合阈值后宣称验证通过。

**H3：** 低 SNR、Rayleigh 衰落、参考/测量频带差异可能改变上述失配与门控表现；当前无实机证据，必须单独验证。

## 3. 候选级约束的数学定义（供新版本设计，不得原地替换V7c）

写 q_A(t)、q_S(t) 分别为从上游已知静态段得到的 Affine/SAPC 坐标，q_0(t)为辅助估计；delta_q(t)=q_S(t)-q_A(t)，q_alpha=q_A+alpha*delta_q。

候选级基本约束为：

1. alpha∈预先固定网格，且 alpha≥0；
2. max_t |alpha*delta_q(t)| ≤ L_extra（新增非仿射校正限幅）；
3. max_t |q_alpha(t)-q_0(t)| ≤ L_total（相对原始辅助估计的总修正上限）；
4. min_n(q_alpha(t_{n+1})-q_alpha(t_n))>0，且全部坐标有限；
5. 每个 fold 必须使用该折未留出的上游静态段拟合候选，折内验证区不参与相位参数拟合；完整训练段拟合仅用于最终推断。

**重要**：第2条只证明新增幅度可行，不能替代第3至5条。由已保存 E 值算出的 alpha 列表不是实际候选的完整可行集。

## 4. 需要独立对照的实验因素

- V7c 原始一次性 Full SAPC 先验幅度拒绝策略（完整冻结的历史基线）。
- 候选级幅度约束但仍使用完全相同CV分数的版本：只研究硬拒绝机制的因果作用。
- 在候选级约束基础上测试不同可观测可信度构型的版本；需要先在新开发集确定配置，再固定算法做新种子盲测，不许借用Oracle Core真值作为门控输入。
- 必须同时比较 Static affine、Full SAPC、V7c、Raw SSWT、Oracle（Oracle只用于评估）。
