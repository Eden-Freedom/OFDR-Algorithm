# V7 图像阅读指南与论文证据等级

## Figure 1：五种方法的应变精度与静态/有效率

**上图**：横轴 Oracle / SSWT / Smoothed / Affine / SAPC；纵轴为**已知非零应变 core 区的 RMSE (με)**，试次级 bootstrap 95% CI。Oracle 是理论计算基线，SAPC 需同时低于原始 SSWT、简单平滑和单斜率优化才值得进一步研究。

**下图**：左纵轴**下游静态 holdout 区**的虚假应变 RMS (με)；右纵轴有效 gauge 比例 (%)。两种单位不可直接根据曲线高度比较。训练段误差小但 holdout 误差大是过拟合的迹象。

## Figure 2：独立 trial 的配对比较

横轴 raw Independent SSWT core RMSE，纵轴 SAPC core RMSE，单位 με。每个点代表一条独立散射体实现 + 两次辅助噪声。**低于黑色 y=x 虚线**才代表本次 trial 改善。必须看配对改善 CI 是否严格大于 0、改善是否只发生于少数 trial，以及失效 trial 的数量。

## Figure 3：校正是否保留真实应变

横轴 gauge 中点 (m)，纵轴实际相位解调应变 (με)。黑色物理真值来自正演积分，原始 SSWT、static affine 和 SAPC 比较。上游 `[0.55,0.98] m` 用于拟合，`[1.08,1.62] m` 的受应变 core **只用于检验**，下游 `[1.78,2.23] m` 是预先保留的静态测试段。

- 必看：5 με 平台的幅值/均值是否保留；边缘响应是否严重变宽；下游本应零应变区是否出现额外伪信号。
- 如果训练段相位下降但 core 真值振幅被压低，不能叫“相位保真”。
- 本次模型固定真值扫描轨迹相同，不证明在两次真实 TLS 扫频不同或没有静态参考段的情况下也有作用。

## 一票否决条件

任一组：1）Oracle 自身正演自检失败；2）V7 训练时引用了真实光频误差/已知应变区域；3）明显降低有效位置比例；4）core 或 holdout 分数没有配对改善；5）调参/测试种子重用但宣称统计显著或泛化——都不允许宣传“新算法提高应变精度”。
